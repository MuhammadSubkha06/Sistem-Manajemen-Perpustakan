# 📚 Sistem Manajemen Perpustakaan Digital

## 📖 Tentang Proyek Ini

Sistem Manajemen Perpustakaan Digital adalah aplikasi berbasis web yang dirancang untuk mempermudah pengelolaan perpustakaan serta memberikan pengalaman peminjaman buku yang lebih modern dan mandiri bagi anggota.

Aplikasi ini dibangun dengan fokus pada:

- Efisiensi administrasi perpustakaan
- Digitalisasi proses peminjaman
- Otomatisasi transaksi dan denda
- Kemudahan akses katalog buku
- Monitoring aktivitas perpustakaan secara real-time

Sistem memiliki dua panel utama, yaitu:

- 🛡️ **Panel Admin**
- 👤 **Panel User / Member**

---

# ✨ Fitur Unggulan

## 🛡️ Panel Administrasi (Control Center)

Fitur khusus administrator untuk mengelola seluruh operasional perpustakaan.

### 👥 Manajemen Data Anggota
- Tambah, edit, dan hapus anggota
- Verifikasi status keanggotaan
- Monitoring aktivitas anggota

### 📚 Manajemen Katalog Buku
- CRUD data buku
- Kelola kategori buku
- Update stok buku
- Upload cover buku
- Detail informasi buku lengkap

### ✅ Sistem Approval Peminjaman
- Verifikasi permintaan peminjaman
- Persetujuan / penolakan peminjaman
- Monitoring status transaksi

### 💰 Sistem Denda Otomatis
- Kalkulasi denda keterlambatan otomatis
- Monitoring pembayaran denda
- Riwayat pembayaran

### 📄 Rekap & Laporan
- Riwayat peminjaman
- Riwayat pengembalian
- Statistik buku
- Data transaksi perpustakaan

---

## 👤 Panel Pengguna (Member Area)

Fitur yang memudahkan anggota dalam menggunakan layanan perpustakaan.

### 🔍 E-Catalog Buku
- Pencarian buku berdasarkan:
  - Judul
  - Penulis
  - Kategori
- Informasi ketersediaan buku
- Detail buku lengkap

### 📥 Pengajuan Peminjaman
- Peminjaman buku secara mandiri
- Status menunggu persetujuan admin
- Monitoring status peminjaman

### 🕘 Riwayat Transaksi
- History peminjaman
- History pengembalian
- Status denda

### 🧾 Struk Digital
User dapat mengunduh atau mencetak:
- Struk peminjaman
- Struk pengembalian
- Struk pembayaran denda

---

# 🔄 Alur Kerja Aplikasi

## 1️⃣ Pengajuan Peminjaman
User memilih buku dan mengajukan peminjaman melalui sistem.

## 2️⃣ Verifikasi Admin
Admin menerima notifikasi dan melakukan verifikasi:
- Disetujui
- Ditolak

## 3️⃣ Pengambilan Buku
Jika disetujui, user dapat mengambil buku di perpustakaan.

## 4️⃣ Pengembalian Buku
Saat pengembalian:
- Sistem memeriksa tenggat waktu
- Denda dihitung otomatis jika terlambat

## 5️⃣ Cetak Struk Digital
Struk transaksi dapat dicetak oleh:
- Admin
- User

Sebagai bukti transaksi resmi.
